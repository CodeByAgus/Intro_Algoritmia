# Fundamentos de Informática - UADE 💻

Este repositorio contiene la resolución de la Guía de Trabajos Prácticos de la materia Fundamentos de Informática (Departamento de Tecnología Informática, UADE)[cite: 2].

El objetivo principal de esta guía es aprender a plantear estrategias de resolución de problemas creando algoritmos, entender cómo construir un programa estructurado en Python, diferenciar estructuras de control, identificar módulos (funciones) y utilizar estructuras de datos unidimensionales y bidimensionales[cite: 2].
